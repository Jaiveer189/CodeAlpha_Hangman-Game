# ⚡ Hangman Pro - Advanced Python GUI Game

A sleek, interactive, and feature-rich desktop Hangman game built from scratch using Python and the Tkinter GUI library. This project showcases structured logic, event-driven programming, and dynamic state management.

Developed as part of my **BCA Data Science / Internship Task 1**.

## 🚀 Features

- **Dynamic Theme Engine:** Switch instantly between ☀️ Light Mode and 🌙 Dark Mode with a smooth UI re-color.
- **Score Streak Tracker (🔥):** Tracks consecutive wins. Guessing a word correctly automatically updates your streak and loads a new word seamlessly.
- **Advanced UX Input:** - Supports standard mouse clicks.
  - Features **Keyboard Binding**—simply type your letter and press `Enter` to submit.
- **Smart Validation:** Bulletproof protection against empty inputs, spaces, duplicate guesses, and special characters without disruptive crashes.
- **Clean Architecture:** Fully modular code using explicit event parameters (`event=None`) to handle multiple input triggers.

## 🛠️ Tech Stack

- **Language:** Python 3.x
- **GUI Framework:** Tkinter (Native Desktop Library)
- **Modules Used:** `random`, `messagebox`
